# Security and privacy boundary

- The Python evaluator reads local JSON and writes local reports.
- The interactive page performs browser-local calculations and transmits no form input.
- No credentials, analytics, cookies, database, external API or action connector are included.
- URLs are evidence metadata; V1 does not fetch them automatically.
- Submitted text is treated as untrusted data, not executable instructions.
- The repository is a demonstration and has not received an independent penetration test.
